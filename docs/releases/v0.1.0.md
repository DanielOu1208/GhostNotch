# GhostNotch v0.1.0 Public Preview

GhostNotch v0.1.0 is the first planned downloadable public preview DMG.

This release is self-signed and not notarized. It is useful for trying the app
without building from Xcode, but it is not a normal trusted macOS distribution
yet.

## Requirements

- macOS 14.0 or newer
- A MacBook display with a notch for the intended visual layout
- Optional: Codex and Claude CLIs for the hover launcher buttons

## Included

- Notch-attached floating terminal island
- Collapsed, hover, and expanded panel states
- `Option+Space` expand/collapse shortcut
- Persistent default-shell PTY session across collapse/reopen
- Ghostty-backed terminal parsing/state through the vendored `libghostty-vt`
  artifact
- App-owned AppKit/CoreText terminal grid renderer
- Hover launcher buttons for Codex and Claude
- Directory presets for launching an agent inside a saved folder
- Native Settings UI for visible agents and directory presets
- Optional Codex and Claude hook installer for working/attention indicators
- Runtime notch measurement with a fallback on non-notch displays

## Install

1. Download `GhostNotch-v0.1.0.dmg` and
   `GhostNotch-v0.1.0.dmg.sha256` from the GitHub Release.
2. Verify the checksum:

   ```sh
   shasum -a 256 -c GhostNotch-v0.1.0.dmg.sha256
   ```

3. Open the DMG.
4. Drag `GhostNotch.app` into `/Applications`.
5. Launch GhostNotch from `/Applications`.

Because the app is self-signed and not notarized, macOS may warn that it cannot
verify the developer. That warning is expected for v0. It should be documented
again in the GitHub Release after the exact downloaded-DMG wording is confirmed.

## Known Limitations

- No Developer ID signing or notarization.
- No automatic updates.
- No Homebrew or App Store distribution.
- No tabs, panes, profiles, or full terminal-app feature set.
- Terminal rendering is good enough for focused testing, but still needs manual
  acceptance across programs such as `less`, `vim` or `nano`, and `top`.
- The app is designed around the built-in MacBook notch. External displays and
  non-notch Macs use fallback sizing.

## Verification

Before tagging this release, run:

```sh
git diff --check
python3 scripts/install-agent-hooks.py self-test
xcodebuild test -project GhostNotch.xcodeproj -scheme GhostNotch -destination 'platform=macOS'
xcodebuild -project GhostNotch.xcodeproj -scheme GhostNotch -configuration Release build
scripts/package-dmg.sh
codesign --verify --deep --strict --verbose=2 dist/GhostNotch.app
hdiutil verify dist/GhostNotch-v0.1.0.dmg
shasum -a 256 -c dist/GhostNotch-v0.1.0.dmg.sha256
```

Also complete the manual checks in [Testing](../testing.md), especially the
collapse/reopen and renderer-sensitive terminal flows.
